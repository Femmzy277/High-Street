# HighStreet

HighStreet is a modern fashion and streetwear storefront built with HTML, CSS, and JavaScript. The project focuses on clean design, responsive layouts, product showcases, and an engaging shopping experience across desktop, tablet, and mobile devices.

## Features

* Responsive design
* Fashion-focused user interface
* Product showcase sections
* Interactive hover effects
* Mobile hamburger navigation
* Search and cart icons
* Currency selector
* Featured collections

## Tech Stack

* HTML5
* CSS3
* JavaScript
* Font Awesome
